    StartEffect(IColorChanger, float, float)

    Start the pulsing effect with a fade out of the image alpha to the minimum transparency then a fade in of the image alpha to the maximum transparency.
    StopEffect needs to be called to stop the effect.

    Declaration
    public void StartEffect(IColorChanger colorChanger, float minimumTransparency = 0, float maximumTransparency = 1)
    Parameters
    Type Name Description
    IColorChanger colorChanger

    Any object containing the color to modify, so we can reset the original color at the end of the effect.
    float minimumTransparency

    Minimum transparency to reach in fade out.
    float maximumTransparency

    Maximum transparency to reach in fade in.

    StopEffect()

    Stop the pulsing effect.
    The effect does not stops immediately it will smoothly transition to the original color.
