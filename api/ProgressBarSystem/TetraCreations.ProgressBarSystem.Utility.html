    CountdownTimer

    Typically used as a cooldown timer. When calling Tick method the time is reduced until it reach 0, then the timer is finished.

    FloatValueCondition

    It is used when we want to trigger some code when a floating value reach a certain threshold.
    Other scripts can subscribe to ConditionIsMet event for that purpose.
    For example when the player health drop below 30% we could set a red overlay on the UI, start a heartbeat sound effect, and a blurry vision using post processing.
